# HandyNotes_ValTeleports

Adds Manaforge Translocator Network node locations for Val.

## Features
- Marks all three teleport nodes on the world map and minimap:
  - Umbral Base Camp
  - Portal to the Forgotten Depths
  - Transit Platform Portal
  - Void Acropolis Interior
- Tooltip on hover shows the node name and description

## Requirements
- [HandyNotes](https://www.curseforge.com/wow/addons/handynotes) (required dependency)

## Notes

Requires the relevant questline to be completed in-game before the network nodes are usable.
